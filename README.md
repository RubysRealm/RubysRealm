# Ruby's Realm

Ruby's Realm is a short-form entertainment automation project.

Current publishing stack:
- automated original story generation
- animated adult characters with distinct speaking voices and visible mouth movement
- physical character actions and burned-in dialogue captions
- watermark-free rendering with Ruby's Realm branding only
- automated caption generation and six-post daily queueing
- Buffer-based TikTok scheduling/publishing
- Vercel-hosted backend services

The TikTok operation is maintained separately from unrelated business and trading systems.
