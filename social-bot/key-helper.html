Social Bot Key

Generate one 32-byte Social Bot key, copy it, then use the exact same key in both places. This helper does not send the key anywhere; generation and copying happen in your browser.

1. Tap GENERATE KEY.
2. Tap COPY KEY.
3. Return to Social Bot → One-time Phone Setup → paste it into Social Bot key → SAVE ON THIS PHONE.
4. In GitHub Actions Secrets, create/update SOCIALBOT_KEY with the exact same value.
