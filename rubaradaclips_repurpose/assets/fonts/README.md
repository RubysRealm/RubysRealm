# Rubarata title font

`Inter-Variable.ttf` is the unmodified Inter variable font distributed by Google Fonts:

https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf

Downloaded October 20, 2026. SHA-256:
`29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031`

The bundled `OFL.txt` contains its SIL Open Font License and copyright notice.
The renderer selects optical size 32 and weights 750 (title) and 650 (part label).
Bundling this file keeps production renders independent of system fallback fonts.
